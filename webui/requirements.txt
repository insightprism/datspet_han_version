# webui (Pet Maker backend) Python dependencies.

# fastapi/starlette are PINNED to a known-good, mutually-tested pair. During this
# integration the venv had resolved to FastAPI 0.139 + Starlette 1.3.1, and in
# THAT combination app.include_router() added no routes to the app (the DPP
# partner router silently failed to mount — observed directly: router.routes had
# 8 entries, app.routes gained 0). Whether the fault was the specific Starlette
# 1.3.1 build or the version mismatch, 0.115.6 / 0.41.3 is a pair where
# include_router provably works (the webui/tests/ suite exercises it). Re-pin
# only after confirming include_router mounts routes on the new pair.

starlette==0.41.3
uvicorn>=0.30
python-multipart>=0.0.9
httpx>=0.24

# pet_factory's env, but the GPU-less pool deploy has no pet_factory install, so it
# must be declared here explicitly (spec Finding 4 / §C.1).
